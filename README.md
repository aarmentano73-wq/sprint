 **IT ACADEMY**

*Data Analyst*


Repositorio que reúne los proyectos y aprendizajes desarrollados durante la formación de Data Analyst. Incluye análisis y visualización con Python y Pandas, EDA, tratamiento y calidad de datos, consultas SQL, MySQL, BigQuery y MongoDB. Los ejercicios abarcan limpieza, transformación, agrupaciones, exploración de datasets y resolución de casos prácticos empresariales, aplicando criterios analíticos para obtener conclusiones fundamentadas.

>* SPRINT 2 **SQL y MySQL**
>>* Consultas, subconsultas.
>>* Filtros y agrupaciones.
>>* Manipulación de bases de datos.
>*  SPRINT 3-4 **BigQuery**
>>*   Consulta y análisis de grandes volúmenes de datos mediante SQL.
>* SPRINT 5 **MongoDB** 
>>*  Trabajo con bases de datos NoSQL.
>>*  Estructuras de datos no relacionales.  
>* SPRINT 7-8-9 **Python**
>>* Pandas. 
>>* Manipulación, limpieza, transformación y análisis de datos.
>>* EDA (Análisis Exploratorio de Datos).
>>*  Exploración, detección de patrones y obtención de conclusiones.
>>*  Visualización de datos.

Este repositorio contiene las actividades y proyectos desarrollados durante la formación en Data Analytics.
Cada sprint incluye ejercicios prácticos, consultas SQL, trabajo con datos y su correspondiente documentación.
