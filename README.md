 **IT ACADEMY**

*Data Analyst*


Repositorio que reúne los proyectos y aprendizajes desarrollados durante la formación de Data Analyst. Incluye análisis y visualización con Python y Pandas, EDA, tratamiento y calidad de datos, consultas SQL, MySQL, BigQuery, MongoDB y Power BI (Power Query, visualizaciones, relaciones entre entidades y medelado). Los ejercicios abarcan limpieza, transformación, agrupaciones, exploración de datasets y resolución de casos prácticos empresariales, aplicando criterios analíticos para obtener conclusiones fundamentadas.

>* SPRINT 2 **SQL y MySQL**
>>* Consultas, subconsultas.
>>* Filtros y agrupaciones.
>>* Manipulación de bases de datos.
>*  SPRINT 3-4 **BigQuery**
>>*   Consulta y análisis de grandes volúmenes de datos mediante SQL.
>* SPRINT 5 **MongoDB** 
>>*  Trabajo con bases de datos NoSQL.
>>*  Estructuras de datos no relacionales.  
>* SPRINT 7-8-9 **Python**
>>* Pandas. 
>>* Manipulación, limpieza, transformación y análisis de datos.
>>* EDA (Análisis Exploratorio de Datos).
>>*  Exploración, detección de patrones y obtención de conclusiones.
>>*  Visualización de datos.
>* SPRINT 10 **API REST**
>>* Reglas que permite la comunicación entre sistemas.
>>* REST: estilo arquitectónico para desarrollar APIs web.
>* SPRINT 11 **Power BI**
>>* Modelado y Limpieza en Power Query.
>>* Indicadores de Rendimiento (KPIs): Creación de métricas para evaluar objetivos globales.
>>* Uso de Medidores y Gráficos: Implementación de medidores (gauges) para comparar medias anuales frente a objetivos y diagramas de
>>* columnas para ventas mensuales.
>>* Análisis de Usuarios por Transacciones: Cálculo de medias en euros y dólares mediante medidas DAX avanzadas y aplicación de formato condicional.

 

Este repositorio contiene las actividades y proyectos desarrollados durante la formación en Data Analytics.
Cada sprint incluye ejercicios prácticos, consultas SQL, trabajo con datos y su correspondiente documentación.
