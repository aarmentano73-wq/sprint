Introducción a BigQuery y SQL en la Nube
Descripción
En este sprint pasamos de trabajar en local (MySQL) a trabajar en Google BigQuery, un entorno serverless orientado al análisis de datos.
El objetivo es entender cómo conectarse a datos existentes, gestionar costes en la nube y aplicar un flujo ELT básico para preparar datos
para su análisis.

Contenido del sprint

  -Creación del proyecto en BigQuery
  -Uso de datasets Bronze, Silver y Gold
  -Creación de tablas externas
  -Limpieza y transformación de datos
  -Consultas SQL para validación y análisis
  -Trabajo en BigQuery Sandbox
  -Subida del proyecto a GitHub

Objetivo
Familiarizarse con BigQuery, comprender el flujo ELT y preparar datos para análisis en un entorno cloud.
